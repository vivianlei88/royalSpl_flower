# 需求文档

## 1. 应用概述

**应用名称**：Royalspl Florist Hong Kong 花店网站

**应用描述**：一个现代高端的香港本地鲜花网店，采用极简奢华画廊风格，为用户提供精选花艺产品的浏览、购买与配送服务。网站以繁体中文为主要语言，搭配优雅英文小标，呈现艺术化的购物体验。后台集成全站通用AI助手系统，基于火山方舟doubao-seed-2-1-turbo-260628模型，为管理员提供内容生成、优化、翻译等智能辅助能力。

## 2. 用户与使用场景

**目标用户**：
  - 香港本地消费者：需要购买鲜花礼品的个人用户
  - 企业客户：需要商务送礼、企业周年庆典用花的企业用户
  - 后台管理员：使用AI助手进行内容创作、商品管理、客服回复等工作

**核心使用场景**：
  - 用户浏览精选花艺产品并通过多维标签筛选商品
  - 用户查看商品详情、选择加购配件、加入购物车
  - 用户完成结账流程并选择配送方式
  - 用户通过会员中心管理订单与个人信息
  - 后台管理员管理商品标签、客户、订单、会员、营销数据
  - 后台管理员使用AI助手生成/优化商品文案、客服回复、营销内容等

## 3. 前置强制硬性规则（全商品模块最高优先执行）

### 3.1 交叉标签统一规范

全站共数百款花艺产品，**所有商品强制采用「交叉标签法 Cross-tagging」**，多维度绑定标签实现前端交叉筛选、AI客服关键词RAG匹配检索。

**规则说明**：
  1. 单款商品必须同时挂载多维独立标签，禁止仅单一分类标签
  2. 标签格式固定使用方括号 `[]`，多标签以顿号分隔
  3. 固定5大标签维度，所有标签仅可从后台预建标签池选取，AI不可随机自创新标签：
     - 场景用途标签：戀愛、生日、母親節、開張、探病、情人節、清明、商務等
     - 核心花材标签：玫瑰、郁金香、芍藥、進口鮮花等
     - 设计风格标签：經典風、韓式、日式極簡、永生花、法式田園風、高級定制等
     - 价格区间标签：HK$300內、HK$300–600、HK$800+、HK$1200+
     - 附加服务属性标签：即日配送、可加賀卡、香港全境配送等
  4. 标签示范：产品「紅色經典韓式玫瑰花束 HK$880」→ `[戀愛]、[生日]、[紅玫瑰]、[經典風]、[HK$800+]、[即日配送]`
  5. 数据同步规则：商品标签数据实时同步至AI客服RAG向量库；前端商品筛选支持多标签交集过滤（AND 逻辑），仅展示同时匹配全部选中标签的产品
  6. 后台标签批量工具：支持批量为多款商品绑定标签、批量新增/删除全域标签池

## 5. 业务规则与逻辑

### 5.1 交叉标签筛选规则

  - 用户在分类/系列页选择多个标签后，前端仅展示同时匹配全部选中标签的产品（AND 逻辑）
  - 商品标签数据实时同步至AI客服RAG向量库，支持AI客服关键词匹配检索

### 5.2 购物车规则

  - 用户点击「加入购物车」按钮，商品添加至购物车
  - 购物车商品数量显示在Header购物车图示徽章
  - 用户修改购物车商品数量或删除商品后，购物车总价实时更新

### 5.3 结账规则

  - 用户在结账页填写收货信息、选择配送方式与支付方式后，点击「确认订单」按钮提交订单
  - 订单提交成功后，系统生成订单号并跳转至订单完成页
  - 订单数据存储至后端数据库

### 5.4 会员规则

  - 用户注册成功后自动登入，跳转至会员中心
  - 用户登入后可查看历史订单、编辑会员资料
  - 用户登出后返回首页

### 5.5 标签管理规则

  - 后台管理员新增标签时，标签自动添加至全域标签池
  - 后台管理员删除标签时，系统删除该标签并解除所有商品与该标签的绑定关系
  - 后台管理员批量为商品绑定标签时，系统更新商品标签数据并同步至AI客服RAG向量库

### 5.6 营销数据获取规则

  - 所有营销管理模块的数据通过Cloudflare Worker后端代理调用Wix API获取
  - 后端代理负责处理API请求，前端无需手动输入API密钥
  - 数据获取后存储至后端数据库，前端从后端数据库读取数据展示

### 5.7 数据存储规则

  - 所有商品数据（商品信息、商品标签）存储在后端数据库
  - 所有客户、订单、会员数据存储在后端数据库
  - 所有营销数据存储在后端数据库
  - 所有AI调用日志（调用人、页面、指令、消耗token、调用时间）存储在后端数据库

### 5.8 AI助手调用规则

  - 所有AI请求通过后端Edge Function统一调用火山方舟doubao-seed-2-1-turbo-260628模型
  - 前端禁止携带任何鉴权信息，所有鉴权由后端处理
  - AI返回结果强制输出繁体中文（香港用语），支持中英双语商品文案
  - 支持批量结构化输出CSV标准格式
  - 自动处理图片URL分隔符转换（; 转 |）
  - OG单图提取逻辑内置为预设指令
  - 请求节流与并发限制防止费用暴增
  - 异常捕获（网络失败、token超限、接口限流、返回格式错乱）统一报错弹窗提示
  - 每次调用记录日志入库

### 5.9 AI用量管控规则

  - 管理员可在AI用量管控页面设置单账号每日最大消耗token上限、全局每日总上限
  - 超出上限后禁止继续调用AI功能，提示「今日用量已达上限」
  - 管理员可临时开关全站AI功能
  - 管理员可单独限制某账号使用权限
  - 管理员可自定义预设提示词模板（花艺专用、客服专用、推文专用）

### 5.10 AI对话历史缓存规则

  - 全局对话窗口的对话历史按管理员账号本地缓存
  - 切换页面不丢失对话历史
  - 管理员登出后清空对话历史缓存

## 6. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户选择多个标签后无匹配商品 | 显示「未找到相关商品」 |
| 用户加入购物车时商品库存不足 | 提示「库存不足，无法加入购物车」 |
| 用户结账时未填写收货信息 | 提示「请填写完整收货信息」 |

| 用户结账时未选择支付方式 | 提示「请选择支付方式」 |
| 用户提交订单时网络异常 | 提示「订单提交失败，请检查网络连接后重试」 |
| 用户登入时用户名或密码错误 | 提示「用户名或密码错误」 |
| 用户注册时用户名已存在 | 提示「用户名已存在，请更换用户名」 |
| 后台管理员删除标签时该标签已绑定商品 | 系统自动解除所有商品与该标签的绑定关系 |
| 后台代理调用Wix API失败 | 提示「数据获取失败，请稍后重试」 |

| 管理员AI用量达到每日上限 | 提示「今日用量已达上限，请明日再试」 |

| 管理员上传CSV/TXT文件格式错误 | 提示「文件格式错误，请上传CSV或TXT文件」 |
| 管理员上传文件大小超限 | 提示「文件大小超限，请上传小于XX MB的文件」 |

## 7. 验收标准

1. 用户打开首页，点击Hero Banner区块的「探索花礼」按钮，跳转至所有花艺分类页
2. 用户在分类页选择多个标签（如「戀愛」+「紅玫瑰」+「HK$800+」），页面仅展示同时匹配全部标签的商品
3. 用户点击商品卡片，跳转至商品详情页，查看商品图片、描述、价格、加购配件选项，选择数量后点击「加入购物车」按钮
4. 用户点击Header购物车图示，开启购物车抽屉，查看购物车商品列表与总价，点击「前往结账」按钮跳转至购物车页
5. 用户在购物车页点击「前往结账」按钮，跳转至结账页，填写收货信息、选择配送方式与支付方式，点击「确认订单」按钮提交订单
6. 订单提交成功后，用户跳转至订单完成页，查看订单号与订单详情
7. 后台管理员登入后台管理系统，进入标签管理-标签池管理页面，新增标签「浪漫風」并指定维度为「设计风格标签」
8. 后台管理员进入商品批量绑定标签工具页面，批量选择多款商品并为其绑定「浪漫風」标签，系统更新商品标签数据并同步至AI客服RAG向量库
9. 后台管理员点击右上角「AI 助手」按钮，弹出全局对话窗口，输入「生成一段花艺科普文案」，AI返回繁体中文文案
10. 后台管理员在商品模块的商品描述输入框右侧点击「AI 生成/优化」按钮，选择「擴寫」指令，AI返回扩写后的繁体中文描述并自动回填输入框
11. 后台管理员进入AI用量管控页面（/admin/ai-settings），设置单账号每日最大消耗token上限为10000，全局每日总上限为100000，查看各管理员调用次数与token消耗记录
